The **Mechanical User** automatically performs player-like interactions on the block or entity directly in front of it once per second. It has nine inventory slots and can use either the upper-left slot or a random occupied slot.

Its interface provides modes for generic clicks, placing blocks, using an item on a block, activating a block with an item, using an item in the air, and interacting with entities. It can perform left- or right-click actions and can act as though the player were sneaking.

The Mechanical User accepts [Speed Upgrades]($content/items/upgrades/speed_upgrades) in its upgrade slot. Each Speed Upgrade makes it operate one additional time per second, but also increases its [Grid Power]($docs/players/grid_power) usage.

Its redstone mode can be set to always operate, operate while powered, operate while unpowered, or operate once per redstone pulse.

The **Breadth-First Search Upgrade** can be placed inside [Transfer and Retrieval Nodes](@excessive_utilities:transfer_nodes) to make their Ping search a Transfer Pipe network from nearest to farthest.

The Ping first visits every reachable pipe one step away from the Node, then every pipe two steps away, and so on. Inventories, tanks, and energy storages near the Node are therefore considered before ones farther along the network.

This is useful when nearby destinations should receive resources before distant destinations, or when a Retrieval Node should prefer nearby sources.

The Upgrade changes only the order in which pipes are searched. It does not increase transfer speed or the amount moved per operation.

Only one Breadth-First Search Upgrade can be installed in a Node. It cannot be installed together with a [Depth-First Search Upgrade](@excessive_utilities:depth_first_search_upgrade).
